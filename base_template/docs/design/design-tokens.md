# 🎨 项目主题与设计系统 Token (Design System Tokens)

> 本文件用于供 AI 与前端开发者读取，硬性约束 UI 界面风格与 Token 变量。

---

## 1. 调色板 (Color Palette)

- **主色 (Primary)**: `#3B82F6` (Brand Blue)
- **辅色 (Secondary)**: `#10B981` (Emerald Green)
- **警告色 (Warning)**: `#F59E0B` (Amber)
- **危险/报错色 (Danger)**: `#EF4444` (Red)
- **深色主题背景 (Dark BG)**: `#0F172A` (Slate 900)
- **卡片/容器背景 (Card BG)**: `#1E293B` (Slate 800)
- **主文本颜色 (Text Main)**: `#F8FAFC` (Slate 50)
- **次要文本颜色 (Text Muted)**: `#94A3B8` (Slate 400)

---

## 2. 排版与字体 (Typography)

- **主字体库 (Font Family)**: `'Inter', -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif`
- **字号阶梯 (Font Sizes)**:
  - H1 页面大标题: `32px` / Bold
  - H2 模块标题: `24px` / Semi-Bold
  - H3 卡片标题: `18px` / Medium
  - Body 正文: `14px` / Regular
  - Caption 说明文字: `12px` / Light

---

## 3. 布局尺寸与圆角 (Spacing & Radius)

- **卡片圆角 (Card Radius)**: `8px`
- **按钮圆角 (Button Radius)**: `6px` / `9999px` (胶囊样式)
- **容器内边距 (Padding)**: `16px` / `24px`
- **组件网格间距 (Gap)**: `12px` / `16px`

---

## 4. 投影与边框 (Shadow & Border)

- **默认边框 (Border)**: `1px solid rgba(255, 255, 255, 0.1)`
- **浮层阴影 (Shadow)**: `0 4px 6px -1px rgba(0, 0, 0, 0.2), 0 2px 4px -1px rgba(0, 0, 0, 0.1)`
