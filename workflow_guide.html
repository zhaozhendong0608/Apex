📍 1. 防迷路导航指示牌协议 (Navigation Guidance Protocol)

在与用户展开多轮需求讨论、A/B 方案决策或排错沟通后，AI 物理强制在回复尾部附带防迷路导航指示牌：
• 📍 当前步骤：明确所在 8 大 Skill/SOP 位置
• 💡 决策小结：1 句话记下用户刚做出的选型决定
• 🚀 决策者建议指令：提供推荐指令、跳过选项与讨论选项，控制权 100% 留给用户。

🛡️ 2. 看门狗护栏 4 大铁律 (Watchdog Guardrails)
  • 单次范围控制：单次改动 ≤ 3 文件 & 零新依赖添加。
  • 日志透传规约：第三方 API 联调必须打印 Request/Response 日志。
  • 零 Mock 假数据铁律：严禁硬编码保底假数据，暴露真实 DB 连通状态。
  • 看板状态确切操控：任务状态改动 100% 走 board.py 脚本。

🛡️ 编码规约与看门狗 4 大通俗铁律：
1. Java & Vue 强规约：Java 统一返回 Result<T> 并由全局异常拦截 BizException；Vue 3 统一使用 <script setup> + Pinia + 拆离 api/*.js。
2. 微创手术：单次最多改动 3 个文件，严禁乱加新的第三方依赖包。
3. 真联调日志：关键业务节点必须打印清晰的【请求入参 Input】与【返参 Payload】日志。
4. 绝对禁止假 Mock：第三方 API 调不通时，严禁 AI 写死的保底假数据掩盖问题！
