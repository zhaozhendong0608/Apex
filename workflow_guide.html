🛡️ 看门狗护栏 4 大通俗铁律：
1. 微创手术：单次最多改动 3 个文件，严禁乱加新的第三方依赖包。
2. 真联调日志：关键业务节点必须打印清晰的【请求入参 Input】与【返参 Payload】日志。
3. 绝对禁止假 Mock：第三方 API 调不通时，严禁 AI 写死的保底假数据掩盖问题！
4. 安全预警：改动数据库 Schema 或全局配置时主动弹出警告。
