# 🔍 Requirement-Discovery (AI 主导的需求发现与澄清流程)

> **技能定位**：专门用于客户只给出一句话、模糊、口语化需求场景。由 AI 主导展开目标、场景、异常、生命周期、上下游、规模与权限，用非技术白话与 A/B/C 选择题澄清需求缺口，并收敛输出标准需求基线。

## 🚀 典型使用场景

1. **零基础/模糊需求发起**：当客户说“帮我做一个告警系统”或“写个订单模块”等模糊一句话需求时。
2. **挖掘隐藏业务逻辑**：在需求分析初期，自主推演失败离线、人为误操作、规模扩大、重启恢复等隐性需求与边界风险。
3. **收敛需求基线**：将未决分支收敛并导出包含“系统行为、边界条件、验收方向”的标准需求基线报告。
