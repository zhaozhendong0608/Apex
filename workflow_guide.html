解耦架构中枢

遵循“外层做工作流控制中枢 (.ai/ + .agents/)，内层做纯粹业务工程 (base_template/ 或 src/)”的极简开发范式，彻底攻克长对话上下文膨胀缺陷。

⚡ 第一层：动态极简名片
< 30 行

文件：.ai/tier1_snapshot.md

永远硬性物理锁定在 30 行以内（<500 Token），包含项目概况、已稳固里程碑、当前唯一 ACTIVE 焦点及顶层铁律。新窗口恢复时 0.5 秒极速吃透！

🧩 第二层：宏观业务大地图
模块 & 拓扑

文件：.ai/tier2_modules.md & tier2_legacy_arch.md

记录系统大模块矩阵索引、交互原型 (mockup.html) 与老代码 4D 元数据 (Route/File/API/Table) 关系图谱，避免“只见树木不见森林”。

📦 第三层：微观任务黑匣子
看板 & 历史

文件：.ai/tier3_status.md & tier3_handover.md

实时跟踪当前正在进行的 Task-XXX，下班发 [5] 时自动归档压缩历史 Changelog 到 handover.md，实现跨会话无损复活。

老项目通用闭环

🧩 强绑定 Skill
legacy-archaeologist

技能名称：老项目逆向考古与代码解密专家

触发方式：输入 0 或 0，顺着接口 /api/refund 找关联文件更新 legacy_arch.md

核心铁律：老项目绝对禁止一次性全量扫描或顺手大重构，必须遵循“鸟瞰骨架 ➔ 路由切片 ➔ 微创修改”！

  • 单次看代码不得超过关联的 3 个切片文件，防止上下文超载。
  • 编写 test_legacy_*.py 探针锁死老业务返回值。

[2] 💻 单焦点契约编码 (Contract-Driven Coding)

看门狗护栏

锁定 status.md 中唯一的 ACTIVE Task，按需加载 Java/Vue 语言规约，在强看门狗护栏下高质高效输出代码。

🧩 强绑定 Skill
coding-standards

技能名称：统一代码规范与 DLD 契约强绑定专家

触发方式：输入 2

语言参考库加载：按需加载 references/java-convention.md（Controller-Service-DAO 三层架构 + R<T> 响应）与 references/vue-convention.md（Composition API <script setup> + Pinia）。

🛡️ 编码看门狗 4 大铁律
  • 单次修改范围：修改文件 ≤ 3 个，零未经过评估的新依赖。
  • 真实联调日志：必须且只能在关键节点打印带【请求入参 Input】与【响应返参 Response】的联调日志。
  • 严禁假 Mock：当接口报错或断联时，严禁自主写保底 Mock 假数据掩盖问题！
  • Solid 核心保护：数据库 Schema、全局拦截器改动高亮预警。

📚 全套 6 大 Skill 技能包全景字典与矩阵

Skill System

汇总 Apex 框架内置的 6 大 AI 专属 Skill 技能包，明晰职责分工、触发条件与确定性物理产出物。

1. 🔍 requirement-discovery
需求发现

职责：AI 主导澄清口语化模糊需求，展开 8-13 维推演。

触发条件：一句话需求或执行 [1] 阶段。

核心产出：结构化需求基线草案、白话对撞决策列表。

2. 🏛️ archetype-architect
原型架构

职责：解析静态原型，继承 Base Shell 强制布局生成交互 HTML。

触发条件：发送 HTML 原型或执行 [1+] 阶段。

核心产出：mockup.html 高保真交互原型、模块 PRD。

3. 📐 design-spec-architect
设计说明书

职责：对齐钧天科技 V1.0 标准，输出 HLD/DLD 8大章节。

触发条件：需求 Sign-off 或结构变动。

核心产出：docs/01~04.md、DDL SQL 脚本。

4. 💻 coding-standards
代码规范

职责：绑定 DLD 契约，加载 Java/Vue 规约，开启看门狗。

触发条件：执行 [2] 单焦点编码阶段。

核心产出：业务源码 (`src/`)、第三方 API 联调日志。

5. 🧪 quality-verifier
质量与排错

职责：小黄鸭探针定位 Bug、TDD 契约碰撞测试、白话终验。

触发条件：执行 [3] 排错、[F] 极速通道或 [4] 验收。

核心产出：小黄鸭根因报告、微创修补代码、白话 Checklist。

6. 🏛️ legacy-archaeologist
老项目考古

职责：逆向扫描路由切片、提取 4D 元数据、写行为锁死探针。

触发条件：执行 [0] 破局老项目阶段。

核心产出：tier2_legacy_arch.md、拓扑图谱、测试探针。
