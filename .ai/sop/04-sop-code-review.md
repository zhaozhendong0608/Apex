# [4] 代码审查机器门禁 (04-sop-code-review)
> **触发**：`[4]`/`CR`/`审查` ｜ **前置**：`[3]` TDD 已闭环 ｜ **产出**：`gate.py` 的 `[LGTM]` 或 `[BLOCKING]`

## 📌 核心目标
在合入集成之前，用**机器门禁**拦住机器能判的问题，把人的注意力留给 `[5]`。

## 🚦 执行
```bash
python3 .ai/scripts/gate.py --staged      # 常规：查暂存区
python3 .ai/scripts/gate.py <文件/目录>…   # 显式变更集
python3 .ai/scripts/gate.py --sql --meta  # SQL 配对 + 工作流自检
python3 .ai/scripts/gate.py --staged --build   # 追加预编译
```
- 退出码：`0 = [LGTM]`、`1 = [BLOCKING]`、`2 = 空变更集/用法错误`（**2 不等于通过**）。
- 审查范围固定为本任务对主干的增量（推荐 `git diff main...HEAD`），不混杂多任务改动。

## ⚙️ gate.py 到底查了什么（能力边界）
| 项 | 手段 | 后果 |
| :--- | :--- | :---: |
| 假 Mock | 扫 `mock/fake/dummy/stub/假数据/兜底`（测试文件豁免） | 🔴 阻断 |
| 新依赖 | `git diff HEAD` 扫 5 类依赖清单新增行 | 🔴 阻断 |
| 公网依赖 | CDN 外链 / `import from https://` / `<script src=http>` | 🔴 阻断 |
| 硬编码密钥 | 密码 / API Key / 私钥 / 带凭据连接串（示例模板豁免） | 🔴 阻断 |
| 最小改动 | 变更文件数 > 3 | ⚠️ 告警 |
| 公共资产 | 路径命中 `base/util/dto/result/config` | ⚠️ 告警 |
| SQL 配对 | `docs/db/migrations` 等 4 个目录，升级脚本须配非空 `rollback_*` | 🔴 阻断 |
| `--meta` | 工作流脚本可编译 + 文档链接 + 能力点 + 指令引用 | 🔴 阻断 |
| **LINT(.py)** | 自研 AST 规则：裸 except / 吞异常 / 可变默认参数 / eval / assert 校验 | 🔴 阻断 |
| LINT(.js/.ts/…) | 外部 CLI（eslint 等），未安装则软跳过 | ⚠️ 软 |

> 机器查不到、必须人眼看的：分层落点、契约语义、可维护性、测试是否真在断言 → 交给 `[5]`。

## ✅ 人工核验 5 维（机器绿了也要过一遍）
1. **看门狗红线**：最小改动 / 零新依赖 / 范围收敛 / 无假 Mock / 零公网 / 公共资产影响清单。
2. **契约一致性**：入参出参错误码与 `detail.md` 完全一致；无自作主张删改；基础单表 CRUD 不做无意义 DTO 转换。
3. **健壮性与并发**：判空前置、浮点受控、无未捕获 NPE；事务范围最小、无长事务/死锁；禁空 catch，关键接口有入参返参日志。
4. **洁净度与性能**：单方法不臃肿、嵌套 ≤3 层、无魔数、无重复块；流/连接/线程池显式释放。
5. **单测质量**：有真实断言（禁 `assertTrue(true)`）；覆盖空值与预期异常；核心逻辑支持反向破坏验证。
