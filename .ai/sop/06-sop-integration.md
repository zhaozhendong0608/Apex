# [6] 集成测试与 E2E 穿透 (06-sop-integration)
> **触发**：`[6]`/`IT`/`集成`/`联调` ｜ **前置**：`[4]` LGTM + TC 矩阵已就绪 ｜ **产出**：IT/E2E 证据 + 0 Error 构建

## 📌 核心目标
脱离单测的 Mock 环境，在近真实拓扑下跑**契约联调 + 中间件吞吐 + 全链路 E2E**，并在此把 TC 轨汇合进来。

## ✅ 三层验证
1. **L2 契约与跨服务**：跨模块/跨服务真实联调与序列化校验；异常链路真实触发（熔断降级→统一错误码）；物理持久化与事务真穿透（写入、约束、幂等）。
2. **L2 中间件与异步**：消息/队列真实生产消费；并发下无乱序无丢失，背压与重试受控，失败进死信。
3. **L3 全链路 E2E**：`输入 → 传输缓冲 → 业务处理 → 落盘 → 展现` 闭环；对照 `docs/test-cases/<m>-testcase.md` 跑 **P0/P1 100%**；加载态/空态/异常态与原型一致；离线环境零公网。

## 🛡️ 5 铁律
1. **禁假 Mock**：暴露真实 DB 状态或受控错误码，不"假装成功"。
2. **消除二次查库**：写入后校验实体内存回显与库最终一致，不靠额外查询掩盖主键回填缺陷。
3. **异常优雅降级**：下游离线/超时须转统一受控响应体，禁裸网络异常与级联雪崩。
4. **100% 离线**：不依赖外网 CDN / 公共 DNS / 云端服务。
5. **数据自愈幂等**：测试数据带前缀（`TEST_IT_`）；事务用例回滚，无事务组件按前缀物理清理。

## 🧷 能力点
`C-6-01` TC 矩阵汇合执行；`C-6-02` 跨服务契约与序列化；`C-6-03` 持久化与事务穿透；`C-6-04` 队列吞吐与背压；`C-6-05` E2E 与 UI 保真；`C-6-06` 5 铁律（禁假数据/单源/降级/离线/自愈）；`C-6-07` 0 Error 构建门禁。
