> 日常请只使用**新编号**。

---

## 一、为什么要改

旧编号有三类混乱：

1. **编号 ≠ 执行顺序**：`10`（技术方案）排在 `2`（编码）之前执行，`04`（评审）在 `07`（门禁）之后；
   `ls` 出来的目录顺序与真实流程相反。
2. **零号家族**：`[00]`/`[0L]`/`[0]`/`[F]`/`[1+]` 五种非数字写法，且 `[0]` 同时指"老项目"和"快修"。
3. **旁路混进主链数字轴**：`3`/`5`/`6`/`13` 是旁路，却和主链共用数字，无法判断"这一步会不会改看板"。

---

## 二、新编号体系

```
[0] 总览（元）
[1] 规划 → [2] 方案 → [3] 编码 → [4] 门禁 → [5] 评审 → [6] 集成 → [7] 验收   ← 主链
[8] 部署 → [9] 发布                                                          ← 交付链
[B1] 老项目  [B2] 快修  [B3] 开发排错  [B4] 线上排障  [B5] 归档  [B6] 恢复      ← 旁路
```

判据：**数字 = 会推进任务状态；`B` 开头 = 不会**。
