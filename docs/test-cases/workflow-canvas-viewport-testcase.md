## 📌 1. 测试基础信息与契约基线

- **测试模块**：`req-management` / 页面 `/req/workflow`
- **测试类型**：纯前端 DOM 尺寸 / 滚动 / 手势行为测试（**无接口、无 DB 断言**）
- **被测对象**：
  - `viewport-workflow-canvas`：固定 360px 可视框
  - `.x6-graph` 内容画布与 SOP-00~09 / B1~B6 图元
  - L 级 ↔ S 级轨道切换按钮
- **运行环境**：Vite dev server `http://localhost:3000/req/workflow`，登录态 `admin`
- **基线数据（修复前，用于对照）**：`.x6-graph` 在 T0 为 49889×110470，T+2s 为 51045×113054，尺寸持续增长
- **统一测量口径**：尺寸均取 `getBoundingClientRect()`，滚动量取 `scrollTop/scrollLeft`，静置采样 200ms × 15 次
