## 1. 业务场景与用户故事 (User Story)
作为买家，我希望将挑选好的商品提交并完成在线支付，以便生成正式订单并安排履约。

## 2. 详细功能点列表
- [ ] **FR-02-A 订单提交与库存扣减**：创建待支付状态订单。
- [ ] **FR-02-B 微信/支付宝接入**：调起第三方支付 SDK。
- [ ] **FR-02-C 支付成功异步回调通知**：更新订单状态为已支付。
