## 📝 缺陷列表 (Defect Tracker Grid)

### 🔴 [BUG-001] 多人 Git 协作状态文件冲突
- **状态**: 🔴 待解决 (OPEN)
- **发现日期**: 2026-08-08
- **影响范围**: 多人同时在不同分支使用 `.ai/status.md` 打卡归档时引发 Git Merge 冲突。
- **临时规避**: 建议团队成员在独立的 Feature 分支开发，主干合并前由一人统一整理 status。
- **解决方案规划**: 4.0 版本将引入脱离 Git 版本号的独立 CLI / SQLite 状态机。
- **解决时间与 Log**: 待解决

- **发现日期**: 2026-08-08
- **影响范围**: 任务验收 (SOP 04) 依赖用户手动打卡与白话 Checklist，缺乏强制的单元测试（`npm test` / `pytest`）阻断门禁。

- **解决方案规划**: 在 SOP 04 验收前，强制插入测试脚本自动检测。
- **解决时间与 Log**: 优化中
